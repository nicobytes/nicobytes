En este codelab vas a construir un agente con el [Agent Development Kit (ADK)](https://adk.dev/). Paso a paso explorarás sus capacidades: desde un system prompt estructurado hasta function tools que llaman APIs reales. Al final, probarás el agente en local con el playground de ADK.

## Qué vas a hacer

- Inicializar un proyecto nuevo de agente con ADK
- Definir un system prompt estructurado en `prompt.md`
- Añadir function tools en Python (`get_weather`, `get_products`)
- Probar la ejecución del agente en local

## Qué necesitas

- Un navegador web, como Chrome
- Conocimientos básicos de Python
- Este codelab está pensado para desarrolladores de nivel intermedio que quieren crear agentes generativos especializados.

**Duración estimada:** 1 h
